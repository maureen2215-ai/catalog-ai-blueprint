# 功能与页面

本页描述供新项目选择的功能规格。选中的模块要落实到页面、数据、接口和验收；未选模块标记“不适用”。名称与界面布局可以改变。

## 基础闭环

| 页面 | 应有的内容与操作 | 必须覆盖的状态 |
|---|---|---|
| 客户商品目录 | 封面、名称、简要规格；搜索、分类、分页或分批加载 | 初次加载、空目录、无搜索结果、网络失败、图片失败 |
| 客户商品详情 | 图片顺序、名称、规格、介绍、复制文案、联系入口；可选公开价格 | 已下架或不存在、慢网、图片切换与保存失败、复制失败、联系方式未配置 |
| 管理员登录 | 会话建立、退出、登录失败提示 | 未登录、过期、账号停用、请求限流 |
| 后台商品列表 | 搜索、状态筛选、新建、编辑、发布、下架 | 空列表、权限失败、批量动作部分失败 |
| 后台商品编辑 | 商品编号、名称、分类、规格、文案、图片顺序与封面 | 新建草稿、已有商品编辑草稿、保存中、版本冲突 |
| 店铺设置 | 店铺名称、介绍、联系入口；按需设置公开信息 | 缺必要信息、无效配置、保存失败 |

客户目录与详情只读正式且已发布的内容。新商品先保存草稿；已有商品可以同时存在对外正式版本和待发布修改。发布要检查必填资料与可用图片，并作为明确动作。

管理员上传真实经营素材应在项目已具备权限和备份边界后进行。开发与演示阶段使用原创示意图及虚构商品。

## 可选模块与依赖

| 模块 | 增加的能力 | 依赖及应先确认的规则 |
|---|---|---|
| Excel 导入 | 上传或选择表格、匹配图片、预检、异常列表、确认应用 | 商品编号如何匹配；同编号更新还是拒绝；手动维护字段能否被覆盖 |
| 价格 | 零售价、内部价、进价；价格草稿、批量调整、异常预警 | 角色可见范围、币种、小数精度、调价权限及价格隐藏策略 |
| 员工 | 登录、查授权资料、复制文案、获取展示图 | 员工账号管理、离职停用、服务端字段隔离 |
| 报价 | 商品清单、数量、允许的调整、有效期、生成分享结果 | 员工与价格模块；价格下限、报价历史可见性、改价后的旧报价如何处理 |
| 购买意向 | 客户选择商品、填写最少必要联系信息、提交后管理员跟进 | 客户知情说明、数据保留期限、防重复与防滥用 |
| 组合商品 | 组成项、用量、附加费用、测算结果、复核提示 | 价格与草稿模块；组成项权限、单位换算、变更传播规则 |
| 推荐与预算筛选 | 自定义推荐入口、顺序、价格区间筛选 | 自定义分类规则；隐藏价格时不得通过筛选泄漏价格 |

导入方式、商品类型和浏览分类分别建模。例：手工创建的普通商品与导入商品可共用列表；组合商品可出现在任意分类。不要用“来自表格”决定能否使用某个编辑页面。

### 可选模块的管理页面

- 员工启用时：管理员账号列表、新建账号、启停账号、凭证重置和角色调整；重置不展示旧密码，不发送未经授权的通知。停用、重置或角色改变时撤销已有会话，防止旧权限继续生效；保护最后一个有效管理员。
- 报价启用时：员工自己的草稿列表与编辑页，支持新建、保存、恢复、删除和正式生成；显示保存状态、版本冲突、过期与恢复失败。正式结果单独查看，不能因编辑草稿覆盖历史报价。
- 购买意向启用时：管理员意向列表、详情、处理状态与备注；默认仅管理员可见联系方式。建议状态为“待处理、跟进中、已关闭”，关闭需记录结果；它们不表示付款或履约。使用者确定保留期限后，提供受控删除或匿名化入口并验证结果，日志不记录联系内容。

## 权限基线

| 内容或动作 | 客户 | 员工（启用时） | 管理员 |
|---|---|---|---|
| 已发布商品资料 | 可读 | 可读 | 可读 |
| 未发布草稿、内部配方 | 不可读 | 默认不可读 | 按管理权限读取 |
| 零售价 | 依公开设置 | 按授权读取 | 可读写 |
| 内部价 | 不返回 | 按授权读取 | 可读写 |
| 进价 | 不返回 | 不返回 | 按管理权限读取 |
| 原始高清图 | 默认不开放 | 默认不开放 | 受控维护 |
| 展示图与缩略图 | 仅已发布商品 | 按授权范围 | 可维护 |
| 发布、改价、账号管理 | 不允许 | 默认不允许 | 独立检查操作权限 |

服务端明确查询与序列化允许字段，媒体接口单独检查访问范围。隐藏按钮、复用前端类型、修改 URL 都不能成为权限校验的替代。

## 定制时怎样改

- 自定义商品字段：先确定字段类型、是否必填、谁能看、是否参与搜索和导入，再改模型与接口。
- 自定义价格：先写计算与取整例子，再实现；客户报价结构不携带内部计算细节。
- 替换联系方式：可以改成电话、聊天链接或表单，但保持配置与展示分开。表单多收一个字段，就应解释用途与访问范围。
- 改页面风格：保留加载、空、错误、权限、过期这些交互状态，检查目标设备上的文字、图片和操作位置。
- 增加支付或库存：作为独立扩展重新设计订单或库存状态机、失败补偿与权限，不能把“购买意向”直接当成已付款订单。

每个定制项都要在新项目需求中写明验收场景，再进入开发。
